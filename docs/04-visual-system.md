# 04 · 视觉系统

## 两套风格，按受众切换

| 维度 | 儿童导览（汪汪队系列） | 家长复盘（本复盘片） |
|---|---|---|
| 背景 | 明亮色块，emoji 为主 | 暖纸白 `#F7F3EA` |
| 主色 | 多色卡片，高饱和 | 深墨蓝 `#142A3A` + 珊瑚橙 `#FF6B4A` |
| 节奏 | 快切、活泼 | 克制、编辑台感 |
| 版式 | 6 个手写场景组件 | 8 类通用版式 + 截屏/成片镜头 |
| 适用 | 陪 2 岁孩子家长 | 想学方法的成人观众 |

## 暖纸感编辑台（复盘片规范）

> 像一位家长把电脑桌面、便签和成片摊在桌上，慢慢讲清一套方法。不是儿童动画，也不是技术发布会。

### 画布与栅格

- 1920×1080 / 30fps / 16:9
- 安全区：左右各 120px，顶部 80px，底部 140px（字幕区）
- 12 栏网格；主视觉占左 7 栏，信息卡占右 5 栏
- 卡片统一 24px 圆角、18px 内边距、极轻阴影

### 色板

| 用途 | 色值 |
|---|---|
| 背景 | `#F7F3EA` |
| 主文字 | `#142A3A` |
| 强调（数字、关键动词） | `#FF6B4A` |
| 次强调（成果/验证） | `#2A9D8F` |
| 高亮（时间线/提示） | `#F4B942` |
| 次级文字 | `#6E7F88` |
| 卡片 | `#FFFFFF`，细边框 `#E6DFD3` |
| 终端窗口 | `#101D2B`，提示符 `#7BE0A0` |

### 字体与字号

- 中文：系统无衬线（PingFang SC / Noto Sans CJK）
- 标题 64px / 700；小标题 42px / 600；正文 34–38px
- 数字 96–120px / 700，珊瑚橙
- 字幕 36px / 600，白字 + 深墨蓝半透明底，底部居中，**不超过两行**

### 动效

- 入场 300–450ms 缓出，轻微上浮 12px；不要弹跳
- 时间线逐点点亮，每点间隔 180ms
- 数字从 0 滚动到目标，600ms
- 转场叠化或纸面滑动 250ms；禁止 3D 翻转、闪烁、强对比跳切

## 镜头版式

`hero / origin / flow / screen / compare / layers / wave / ending` 八类通用版式在 `FullScene.tsx` 中实现；`board.ts` 只描述"这一段画什么"：

```ts
{kind: 'nums', title: '成果', nums: [
  {v: '10', l: '条成片'}, {v: '34.6', l: '分钟'}, {v: '142.6', l: 'MB'}
]}
```

新增 `shot` 与 `clip` 后，抽象信息图与真实证据可以混排：

- **`shot`**：`<Img>` 展示真实截屏 PNG，1320×742，圆角窗口 + 轻阴影
- **`clip`**：`<OffthreadVideo>` 静音播放真实成片，用 `startFrom = clipFrom * 30` 裁剪片段

### 截屏窗口的三个坑

1. 图片过高会把主标题顶出去 → 用 compact 版式把 `frameWrap` 的 `top` 下移到 248，`bottom` 收到 76。
2. 顶部计数写死 `/39` → 改成 `boards.length`，当前显示 `/51`。
3. 底部注释被字幕压住 → 移除 `shot`/`clip` 的 `note` 字段，信息放在标题和字幕里。

## 真实截屏怎么生成

`examples/gen_evidence.py`（原工程 `scripts/gen_evidence.py`）：

1. 从本机采集真实数据：`video doctor` 输出、文件树与 mtime、MP4 元数据、SRT 片段、WORKFLOW.md、`video --help`、BGM 文件列表。
2. Pillow 渲染成统一风格 PNG：终端深色窗 / 文档浅色窗，关键行用珊瑚橙高亮。
3. 中文用 STHeiti 回退，避免 Menlo 显示方块。

BGM 波形直接读 WAV 的 PCM 数据画柱状图；成片画面用 Remotion 的 `OffthreadVideo` 直接播放，不需要 ffmpeg 预抽帧。

## 素材红线

**可用**：本工作区自制 MP4 抽帧、终端录屏、文件树截图、BGM 波形、CLI 输出、自制 SVG/React 信息图。

**不可用**：官方 Logo、角色原图、原片画面、第三方主题曲音频。

特别注意：**马赛克 / 大色块 / 近似外形不等于安全**。只要观众能从"配色 + 品种特征 + 道具"的组合认出是哪只狗狗，商用仍有实质性相似风险；角色只能做与具体角色无对应关系的抽象图形。
