# 10 · 版权边界

> 本页是创作者的经验总结，不构成法律意见。商用前请自行核实目标地区的著作权、商标与平台规则。

## 绝对不要用

- 官方角色形象、海报、LOGO、玩具图（美术作品 + 商标）
- 动画原片画面、片段、表情包（视听作品）
- 原版主题曲、角色台词、电影原声（音乐 / 录音制作者权）
- 从网上下载的"完整版主题曲"当 BGM，即使只截取几秒

## 可以安心用

- 原创中文解说文案：事实性介绍（季数、年份、角色职能、剧情概述）
- 本流水线自制的 emoji / 色块信息图
- 原创合成 BGM：纯器乐，或用共振峰合成的童声（**非真人采样**）
- CC0 无署名音乐
- 少量"适当引用"并注明作品名与角色名，控制比例、不替代正片观看

## 三个常见误区

| 误区 | 为什么错 |
|---|---|
| "没赚钱就不侵权" | 非商业使用不当然免责，传播行为本身就可能构成侵权 |
| "写了侵删就没事" | 声明不能替代授权 |
| "国外动画随便剪" | 著作权按条约跨国保护，平台 Content ID 同样会识别 |

## 抽象化的安全边界

马赛克 / 大色块 / 近似外形**不等于安全**。只要观众能从以下组合认出具体角色，就有实质性相似风险：

- 配色（如黄色 + 蓝色工程帽）
- 品种特征（如斗牛犬耳朵、德国牧羊犬体型）
- 道具（如铲子、望远镜、消防车）

正确做法：只做**与任何具体角色都没有对应关系**的抽象图形，并在卡片上用文字说明职能，而不是用视觉暗示身份。

## 音频的边界

- 官方 / 第三方主题曲只能用于**本地分析**，不进成片。
- 分析只取调性、听感来源、编制、节奏动机等风格参数。
- 旋律、和声、动机必须原创；不采样、不变调、不逐音符复制。
- 每版 BGM 独立输出 A/B，保留迭代痕迹，便于证明原创过程。
