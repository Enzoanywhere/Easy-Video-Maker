# 05 · BGM 方法论

## 七版迭代的教训

| 版本 | 尝试 | 反馈 |
|---|---|---|
| 1 · march | 激昂进行曲，号角 + 鼓点 | 不像目标曲 |
| 2 · fusion | 加入唢呐、二胡等民乐 | 方向仍偏 |
| 3 · strings | 小提琴 / 大提琴弦乐 | 情绪不对 |
| 4 · catchy | 抓耳儿童曲 | 有点接近但不同 |
| 5 · rock | 摇滚编制 | 完全听不出来 |
| 6 · rock2 | 旋律重塑 | 调性还是不对 |
| 7 · choral | 合成童声合唱 + 共振峰 | 命中核心听感 |

**最大教训**：一开始只抓 BPM 和能量，全部走错。真正的优先级是：

> **调性 > 听感来源（人声 / 器乐）> 编制 > 节奏动机 > 旋律**

对童声主题曲而言，"神似"的核心可能是**真人童声合唱的共振峰**，而不是号角、弦乐或更快的鼓点。定位到 A 大调 / F# 小调与童声共振峰之后，才做出对味的合成版。

## 分析工作流

```bash
video analyze /path/to/reference.mp3 --format text
```

分析器（`scripts/audio/analyze_reference.py`）输出：

- 调性：STFT / CQT / CENS chroma 汇总
- 频谱平坦度：低平坦度 = 强谐波 + 多共振峰，提示可能含合唱人声
- 共振峰峰位：判断是童声还是成人声、是合唱还是独唱
- onset 间隔与 BPM：自相关初筛
- 频谱质心、HPSS 谐波/打击分离

**重要限制**：

- `video analyze` 的 BPM 是初筛值。本次输出 95.7，而历史人工确认是 126；冲突时以人工结论和用户试听为准。
- pYIN / YIN 在密集失真混音上不可靠，**不要用算法自证旋律**。分析只取风格参数，不逐音符复制。

## 创作规则

1. 只取风格参数：调性、人声/器乐、编制、节奏动机。
2. 旋律、和声、动机完全原创。
3. **不采样、不变调、不逐音符复制**。
4. 每版输出独立 WAV，A/B 对比，不覆盖在用的 `bgm.wav`。
5. 交给用户试听决定，不用频谱指标代替耳朵。

## 给 AI 的 prompt 模板

> 先分析这段参考音频的调性、听感来源、编制、节奏动机，确认后再写原创旋律。
> 优先级：调性 > 人声/器乐 > 编制 > 节奏 > 旋律。
> 要求：原创、不采样、不变调、不逐音符复制；输出独立 WAV 文件，不覆盖在用 BGM。
> 验证：不要用 pYIN 自证；给我 2–3 版让我试听。

## 合成实现

七个生成器都在 `video-toolkit/scripts/bgm/`，纯 Python：

- 基础：`math` / `wave` / `struct` / `random` 生成 16bit PCM
- 进阶：`numpy` / `scipy` 做包络、滤波、和弦与共振峰
- 输出：22050Hz 或 44100Hz 单声道 WAV，首尾淡入淡出
- 解码参考音频：macOS 自带 `afconvert -f WAVE -d LEI16@44100 -c 1`

## 混音参数

| 参数 | 导览片 | 复盘片 |
|---|---|---|
| BGM 电平 | 0.12（12%） | 0.10（10%） |
| 淡入淡出 | 首尾 2 秒 | 首尾 4 秒 |
| 时长 | 90 秒 | 480 秒，片长 672 秒时循环 |
| 风格 | 原创 kids / 童声合唱 | 原创 lo-fi documentary，F 大调 / BPM 92 |

复盘片刻意用柔和电钢 + 拨弦 + 低音 + 刷镲，**不做童声或进行曲**，避免和 IP 主题曲混淆。
